# 1. Download official DMG installer from GitHub Releases
$curl -LO https://github.com/Ashutosh-Repos/takemock/releases/download/v0.1.0/TakeMock_0.1.0_aarch64.dmg
# 2. Mount and drag TakeMock to /Applications
$open TakeMock_0.1.0_aarch64.dmg
# 3. Clear Gatekeeper quarantine for unsigned open-source binary
$xattr -cr /Applications/TakeMock.app
Note :   For the first time you open TakeMock, macOS may show a warning because the app is not signed with Apple Certificate because I didn't pay apple $99/year for being in the "Apple Developer Program". Solution is simple - Go to Applications, right-click TakeMock.app, and click Open,

Core Capabilities

Built for focused exam preparation.

No distracting web portals, network timeouts, or cloud latency during timed drills.

Authentic NTA Engine

Matches the official 5-color palette (Answered, Unanswered, Marked for Review, Answered & Marked). Evaluates marked-for-review answers per NTA exam guidelines with per-section countdown timers and negative marking (+4 / -1).

Vector Formula Typesetting

KaTeX renders integrals, matrices, fractions, and chemical formulas as crisp vector curves on Retina displays. Formulas never degrade into blurry low-resolution JPEG images.

100% Local & Private

All mock papers, attempts, answers, and the Mistake Vault stay on your Mac in IndexedDB. No accounts, telemetry, or remote servers. Runs entirely unplugged.

Architecture

Tauri v2, Rust & React 19.

A lightweight desktop runtime using macOS WKWebView and Rust Cocoa bindings instead of bundling a full Chromium browser.

Tauri v2 Runtime

Provides the native OS bridge using macOS WKWebView, keeping disk usage under 10 MB and minimizing RAM footprint.

Rust Backend

Handles Cocoa AppKit interop via objc2, window vibrancy, native menu registration, and dock appearance sync.

React 19 & TypeScript Frontend

Fast, type-safe exam simulator interface built with Base UI primitives, Tailwind CSS, and local KaTeX mathematical typesetting.

IndexedDB Storage

Local database storing question packs, exam sessions, attempt histories, and performance analytics entirely on your Mac.
