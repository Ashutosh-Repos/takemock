Capabilities

Built around actual test conditions.

TakeMock replicates the NTA test screen used in JEE and NEET. It removes browser latency, runs completely offline, and saves answers in local IndexedDB.

Official CBT Mechanics

5-state palette: Answered, Not Answered, Marked for Review, Answered & Marked, and Not Visited. Correctly evaluates answered-and-marked questions per NTA rules with per-section timers (+4 / -1 or custom scoring).

KaTeX Equation Typesetting

Renders LaTeX math formulas, matrices, integrals, and chemical reactions directly to vector paths on Retina displays. No blurry equation images or network font loading.

Mistake Vault

Automatically logs incorrect and skipped questions across test sessions. Review accuracy distributions, time spent per problem, and bookmark questions for targeted re-drilling.

Local-First & Portable Data

All test data stays in your Mac's IndexedDB without cloud accounts or telemetry. Build mock tests with the visual editor or import/export standard JSON question packs.

Developer & Packaging

Tauri v2 + Rust + React 19

Self-contained desktop application under 10 MB. Uses macOS WKWebView and Cocoa AppKit interop without shipping Chromium.

# Clone source repository and install Node dependencies
$ git clone https://github.com/Ashutosh-Repos/takemock.git
$ cd takemock && pnpm install
# Start local development window with instant hot reload
$ pnpm tauri dev
# Build production DMG bundle
$ pnpm tauri build

Gatekeeper Notice for First Launch
TakeMock is distributed as open-source software without an Apple Developer ID certificate. On first launch, macOS Gatekeeper may show an "unidentified developer" prompt.

How to open: Right-click (or Control-click) TakeMock.app in your Applications folder and select Open, then click Open in the dialog.
Alternatively, clear the quarantine attribute via Terminal:
xattr -cr /Applications/TakeMock.app
