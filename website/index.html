A particle of mass \( m \) moves under a central potential \( V(r) = -\frac{k}{r} \). The total energy of the orbit is given by:
E = \frac{1}{2} m \dot{r}^2 + \frac{L^2}{2 m r^2} - \frac{k}{r}
A \( E < 0 \) results in a bound elliptical trajectory
B \( E = 0 \) results in a circular stable orbit
C \( E > 0 \) gives closed periodic trajectories
D Total angular momentum is not conserved

Engineered For Performance

Everything you need for serious exam simulation.

TakeMock is built specifically for competitive candidates and developers who demand zero lag, full offline control, and accurate Computer-Based Test execution.

Authentic CBT Palette Engine

Implements the exact 5-state test engine used by premier national exam bodies: Answered, Not Answered, Marked for Review, Answered & Marked for Review, and Not Visited. Seamless section jumps and negative marking parity.

KaTeX Mathematical Typesetting

First-class rendering for LaTeX expressions, matrices, integrals, vectors, and chemical equations. Zero blurry equation images — every symbol renders razor-sharp on Retina displays.

100% Local-First & Private

All exams, attempts, analytics, and answers stay exclusively on your Mac in IndexedDB. No servers, no accounts, no sign-in required, and zero telemetry. It works completely offline on flights, libraries, or unplugged.

Mistake Vault & Deep Analytics

Automatically catalogues every wrong answer, skipped question, and edge case. Review your time-per-question distributions, subject accuracy breakdowns, and bookmark tough items for targeted re-drilling.

Question Pack JSON Ecosystem

Built-in visual Paper Builder lets you assemble mock tests in minutes. Import or export standard JSON question packs to share full mocks or specific drills with your study group or students.

Keyboard-First Workflow

Engineered for high-speed navigation. Switch sections with Cmd+1 / Cmd+2, toggle sidebars with Cmd+B, navigate questions with arrow keys, and submit responses without lifting your hands from the keys.

macOS Integration

Designed to feel at home on your Mac.

TakeMock doesn't look like an Electron port or a generic browser wrapper. It embraces macOS architecture with native Cocoa AppKit interop.

UnderWindowBackground Vibrancy
Native translucent titlebar and side navigation that harmonizes with your desktop wallpaper and system color accents.
macOS Tahoe Adaptive Icon Engine
Seamlessly adapts to macOS 26 Tahoe system icon styles: displays crisp Light icon by default, supports native Liquid Glass (Clear) & Tinted shaders, and swaps to deep Dark mode in real-time.
Native macOS Menu Bar & Hotkeys
Standard macOS TakeMock, File, Edit, and View menus with native About panels, preferences shortcuts, and Window management.

Architecture

Built on a modern, robust desktop foundation.

TakeMock is built with an efficient, memory-safe stack that keeps binary size tiny and eliminates electron-style memory bloat.

Tauri v2 Core Engine

Provides the secure cross-platform bridge using macOS WKWebView and native binary IPC without bundling Chromium.

Rust System Backend

Handles macOS AppKit interop via objc2, window vibrancy, native menu orchestration, and icon appearance observers.

React 19 & TypeScript UI Layer

Type-safe component tree styled with Tailwind CSS and Base UI for smooth animations, accessible modals, and instant hotkeys.

IndexedDB Persistence

Structured, zero-latency local database storing question packs, exam sessions, attempt histories, and performance metrics.

Building TakeMock locally from source
$ git clone https://github.com/Ashutosh-Repos/takemock.git
$ cd takemock && pnpm install
# Launch instant hot-reloading development environment
$ pnpm tauri dev
# Build production macOS DMG installer bundle
$ pnpm tauri build

macOS Gatekeeper First-Launch Note
Because TakeMock is an open-source community release distributed independently without an Apple Developer Paid Subscription ($99/yr), macOS may display an "App cannot be opened because it is from an unidentified developer" dialog on first launch.

To open: Right-click (or Control-click) TakeMock.app in your Applications folder and select Open, then click Open in the prompt.
Alternatively, run this in Terminal:
xattr -cr /Applications/TakeMock.app
