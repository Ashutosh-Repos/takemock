Capabilities

Built around actual test conditions.

TakeMock replicates the NTA test screen used in JEE and NEET. It removes browser latency, runs completely offline, and saves answers in local IndexedDB.

5-State CBT Palette Engine

Tracks Answered, Not Answered, Marked for Review, Answered & Marked, and Not Visited. Correctly includes answered-and-marked questions in the final score calculation per NTA rules.

KaTeX Equation Typesetting

Renders LaTeX math formulas, matrices, integrals, and chemical reactions directly to vector paths on Retina displays. No blurry equation images or network font lag.

Local IndexedDB Storage

Test sessions, question packs, attempts, and error logs are stored on your Mac in IndexedDB. No server requests, no accounts, and no telemetry tracking.

Mistake Vault

Logs incorrect and skipped questions across sessions. Shows time-per-question distribution and allows bookmarking specific questions for focused re-drilling.

JSON Question Packs

Build mock tests with the visual paper editor, or import and export question sets using standard JSON files for sharing with study groups.

Keyboard Shortcuts

Switch sections with Cmd+1 / Cmd+2, toggle navigation with Cmd+B, and navigate questions with arrow keys without using the mouse.

Platform Integration

Native macOS AppKit integration.

Built with Tauri v2 instead of Chromium. Interacts directly with AppKit for window translucency, menu items, and dock appearance.

AppKit Window Vibrancy
Uses NSVisualEffectView under window backgrounds to follow macOS system appearance and wallpaper tinting.
Dock Icon Appearance Sync
Tracks system appearance changes via NSApplication.setApplicationIconImage. Uses the default light icon, respects macOS Clear and Tinted styles, and loads the dark icon in dark mode.
Cocoa Menu Bar & Shortcuts
Standard macOS TakeMock, File, Edit, and View menus with native About dialogs, window controls, and keyboard bindings.

Architecture

Tauri v2, Rust, and React 19.

A lightweight desktop runtime using macOS WKWebView and Rust Cocoa bindings instead of bundling a full Chromium browser.

Tauri v2 Runtime

Provides the application bridge using macOS WKWebView, keeping disk usage under 10 MB and minimizing RAM footprint.

Rust Backend

Handles Cocoa AppKit interop via objc2, window vibrancy, native menu registration, and icon appearance observers.

React 19 & TypeScript Frontend

Type-safe component tree using Base UI primitives, Tailwind CSS, and local KaTeX typesetting.

IndexedDB Storage

Local database storing question packs, exam sessions, attempt histories, and performance analytics entirely on your Mac.

Gatekeeper Notice for First Launch
TakeMock is distributed as open-source software without an Apple Developer ID certificate. On first launch, macOS Gatekeeper may show an "unidentified developer" prompt.

How to open: Right-click (or Control-click) TakeMock.app in your Applications folder and select Open, then click Open in the dialog.
Alternatively, clear the quarantine attribute via Terminal:
xattr -cr /Applications/TakeMock.app
